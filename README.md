# chat-clinic

A chat clinic application.

## Repository Setup

This repository is being migrated to `chat-clinic-hub`. To initialize the main branch and push to the new repository, run:

```bash
./initialize-main.sh
```

Or manually execute:

```bash
git remote add origin https://github.com/joaotiheci/chat-clinic-hub.git
git branch -M main
git push -u origin main
```
